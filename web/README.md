# 📝 Todo App — Frontend Web

Interface React pour l'application Todo, consommant l'[API Todo](../api).

## 🚀 Stack technique

- **React** 19
- **Vite** 8
- **React Router** v7
- **Axios** (avec interceptors)
- **Context API**

## 📋 Prérequis

- Node.js >= 20
- L'API en cours sur `http://localhost:5000`

## ⚙️ Installation

```bash
npm install
cp .env.example .env
npm run dev
