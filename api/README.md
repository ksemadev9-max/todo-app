# 📝 Todo API

API REST pour une application de gestion de tâches.

## 🚀 Stack technique

- **Node.js** v24 LTS
- **Express** 5.x
- **MongoDB Atlas** (cloud)
- **Mongoose** 9.x
- **JWT** (authentification)
- **bcryptjs** (hash passwords)

## ⚙️ Installation

```bash
npm install
cp .env.example .env
# Remplir .env avec vos vraies valeurs
npm run dev
